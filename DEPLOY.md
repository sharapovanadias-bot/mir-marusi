# Как выложить «Мир Маруси» в интернет

Сайт — чистая статика: HTML + CSS + JS, без сборки и без бэкенда.
Все пути относительные, поэтому он заработает на любом хостинге **без единой правки**.

Архив со всем сайтом: **`/home/user/mir-marusi-site.zip`** (8.6 МБ, 116 файлов).

---

## Вариант 1. Netlify Drop — быстрее всего, 30 секунд

1. Открыть **https://app.netlify.com/drop**
2. Перетащить туда файл `mir-marusi-site.zip` (или саму папку `mir-marusi`)
3. Готово — сразу выдаётся ссылка вида `случайное-имя.netlify.app`

Регистрация не нужна, но без неё сайт живёт ограниченное время.
Если войти в аккаунт — останется навсегда, имя можно поменять в настройках,
там же бесплатно подключается свой домен и HTTPS.

В архиве уже лежит `netlify.toml` с правильным кэшированием шрифтов и картинок.

## Вариант 2. Vercel

1. **https://vercel.com/new** → «Deploy» без Git-репозитория
2. Загрузить папку проекта
3. Framework Preset: **Other** (это статика, сборка не нужна)

## Вариант 3. GitHub Pages — если нужен контроль версий

```bash
cd /home/user/mir-marusi
git init && git add -A
git commit -m "Мир Маруси — сайт бренда"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/mir-marusi.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Source: main / (root)**.
Через минуту сайт будет на `ВАШ_ЛОГИН.github.io/mir-marusi/`.

Файл `.nojekyll` уже добавлен — без него GitHub игнорировал бы служебные папки.

## Вариант 4. Обычный хостинг / свой домен

Просто залить содержимое папки `mir-marusi` в корень сайта (`public_html`, `www`)
по FTP. `index.html` должен оказаться в корне.

## Что проверить после публикации

- [ ] Шрифты подгрузились — заголовки рукописные (Caveat), текст — Neucha.
      Если шрифты не встали, сервер не отдаёт `font/woff2` — на Netlify/Vercel/Pages это работает из коробки.
- [ ] Цена отображается как «690 ₽» — знак рубля на месте.
- [ ] Лента каракулей на главной едет.
- [ ] Корзина считает: 1 книга = 1 040 ₽ с доставкой.

## Важно про домен

В `index.html` в двух местах — `<link rel="canonical">` и JSON-LD разметке бренда —
стоит заглушка `https://mirmarusi.example/`. **После выбора настоящего домена её нужно
заменить**, иначе поисковики будут считать канонической несуществующую страницу:

```bash
cd /home/user/mir-marusi
sed -i 's|https://mirmarusi.example|https://ВАШ-ДОМЕН|g' index.html
```

Остальные 14 страниц пока без `canonical` — на работу сайта это не влияет,
но перед запуском рекламы/индексации их стоит проставить.

## Ограничения прототипа

Это фронтенд-прототип: корзина хранится в `localStorage` браузера,
платёжный шлюз не подключён, форм-отправка не настроена.
Для реальных продаж нужен бэкенд или подключение готового решения
(например, кнопки оплаты ЮKassa / Tinkoff или платформы вроде Ecwid).
