# Что взято из книги «Зима Маруси» (PDF, 160 стр., 148×210 мм)

Источник: `/home/user/uploads/Зима Маруси. 2.0.pdf`

## 1. Шрифты — теперь настоящие шрифты книги

В PDF встроены (subset-версии):

| Шрифт | Где в книге | Где на сайте |
|---|---|---|
| **Caveat** / Caveat-Bold | заголовки, рукописные вставки, реплики | `--hand` — логотип, заголовки-«от руки», подписи |
| **Neucha** / Bold / Oblique | основной текст книги | `--serif` — текст, названия, лиды |
| PT Sans Bold, DejaVu | служебные, единичные | не используются |

Оба шрифта распространяются по **SIL Open Font License** — их можно легально использовать на сайте.
Скачаны полные версии, обрезаны под кириллицу + пунктуацию, сконвертированы в woff2:

- `assets/fonts/caveat.woff2` — 130 КБ (вариативный, 400–700)
- `assets/fonts/neucha.woff2` — 38 КБ

Подключены через `@font-face` + `<link rel="preload">` на всех 15 страницах, `font-display:swap`.

⚠️ **В Neucha нет знака ₽.** Поэтому цены и числа выводятся отдельным стеком `--num`
(UI-шрифт, `tabular-nums`) — иначе цифры и валюта рендерились бы разными шрифтами.

## 2. Иллюстрации

Из PDF извлечено 96 уникальных изображений. Отобрано и оптимизировано (≤1100px, JPEG q82):

- `assets/img/winter/` — **22 сюжетные акварели** (1.9 МБ): обложка, снежинки, Дед Мороз,
  снежная крепость, иглу, каникулы, Егор за столом, Лиза, финал.
- `assets/img/doodles/` — **28 «каракулей»** (324 КБ): детские рисунки на тетрадной
  бумаге в клетку и линейку — снеговики, варежки, ёлки, схемы, ёжик, замок.

## 3. Стилистика

Палитра книги совпала с уже принятой палитрой сайта — кремовая бумага `#F8F8E8`,
тёплая охра, пыльно-голубой, коричневые карандашные линии. Менять ничего не потребовалось.

Новые элементы оформления:
- `.doodles` — бесконечная лента детских рисунков из книги (пауза на hover,
  отключается при `prefers-reduced-motion`);
- `.bookspread` — разворот-витрина второй книги на главной.

## 5. Карточка второй книги

`book-two` заполнен реальными данными: «Зима Маруси», серия «Дневник Маруси», книга вторая,
Надежда Шарапова, 160 страниц, 148×210 мм, оглавление, фрагмент из главы «1 декабря»,
галерея из 6 разворотов.

Статус — `soon`: **цена неизвестна**, поэтому выводится «Готовится к выходу — цену объявим
позже», CTA «Сообщить о выходе», JSON-LD `availability: PreOrder` без цены.
