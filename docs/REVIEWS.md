# Отзывы: как собирать и публиковать

## Правило

На сайте публикуются **только настоящие отзывы реальных покупателей**.
Выдуманные отзывы не пишем — ни «для примера», ни «временно, потом заменим».

Пока настоящих отзывов нет, `MM.reviews = []`, и на сайте показываются честные
placeholder-блоки с текстом: «Мы публикуем только настоящие отзывы покупателей.
Пока их нет — здесь честно пусто».

Причина не только этическая. Выдуманный отзыв — это утверждение о факте покупки,
которого не было. В ЕС это подпадает под Директиву о недобросовестной коммерческой
практике (Приложение I, п. 23b — запрет публиковать отзывы без проверки, что их
оставил реальный покупатель), в РФ — под ст. 5 закона «О рекламе» (недостоверная
реклама). Штрафы получает продавец, а не разработчик сайта.

## Как публиковать полученный отзыв

Один отзыв = один объект в массиве `MM.reviews` в `assets/js/data.js`.

```js
MM.reviews = [
  { id:'r1',
    product:'col-friends',   // id из MM.products; '' — отзыв о бренде в целом
    author:'Ирина',          // как покупатель разрешил себя назвать
    role:'parent',           // 'parent' | 'child'
    childAge:7,              // для role:'child' — возраст автора
    city:'Казань',           // необязательно
    date:'2026-08-14',       // ISO, дата получения отзыва
    rating:5,                // 1–5, необязательно
    text:'…',                // дословно, без правок смысла
    verified:true }          // покупка подтверждена (номер заказа / чек)
];
```

После правки данных: `python3 bump.py` → коммит → пуш.
HTML менять не нужно: главная и вкладка «Отзывы» на странице товара
подхватывают массив автоматически. Отзыв показывается только на странице
своего товара; `role` определяет колонку — «родители» или «дети».

### Что можно и нельзя редактировать в тексте

- **Можно:** опечатки, пунктуация, сокращение с многоточием `…` без искажения смысла.
- **Нельзя:** усиливать похвалу, убирать критику, склеивать несколько отзывов в один,
  добавлять от себя названия товаров или преимущества.
- Если отзыв содержит критику — публикуем как есть. Раздел из одних пятёрок
  вызывает меньше доверия, чем честная смесь.

## Как получить первые отзывы

1. **Вкладыш в посылку** — карточка с QR на короткую форму и фразой Маруси:
   «Напиши мне, что тебе понравилось». Отдельные поля для ребёнка и родителя.
2. **Письмо через 10–14 дней после доставки** — когда книгу успели прочитать.
   Одна просьба, без скидки в обмен на отзыв: оплаченный отзыв нельзя
   публиковать как обычный, его придётся помечать.
3. **Для цифровых товаров** — экран после скачивания PDF со ссылкой на форму.

### Согласие

В форме — обязательная галочка: «Разрешаю опубликовать мой отзыв на сайте
"Мир Маруси" с указанием имени и города». Отзывы детей публикуются только
с согласия родителя. Храним: дату согласия, номер заказа, исходный текст.

### Проверка покупки

`verified:true` ставим, только если отзыв связан с номером заказа или чеком.
Без подтверждения — публикуем без бейджа.
